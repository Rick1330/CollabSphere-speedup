# Tool Handoffs

## Purpose
Tool handoffs preserve context when one tool, agent, or execution mode
hands work to another.

They are lighter than full session logs and more explicit about:
- what was built in one tool
- what the next tool must respect
- what the next action should be

## Naming
- `YYYY-MM-DD-from-tool-to-tool-topic.md`

## Minimum contents
- goal
- current repo state
- what changed
- what not to undo
- next intended action
