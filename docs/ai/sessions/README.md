# Session Logs

## Purpose
This directory stores durable session records for non-trivial work.

Session logs are the primary continuity layer between:
- different days
- different tools
- different contributors

## Rules
- Create one markdown file per meaningful session.
- Use `docs/ai/templates/SESSION_LOG_TEMPLATE.md`.
- Name files `YYYY-MM-DD-topic.md`.
- Include exact next steps and validation evidence.

## Read order
When resuming work:
1. Read `docs/architecture/current-state.md`
2. Read the most recent relevant session log
3. Read the relevant domain bundle in `docs/ai/bundles/`
