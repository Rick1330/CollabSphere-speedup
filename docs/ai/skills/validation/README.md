# Validation Skills

## Purpose
These skills provide reusable validation checklists for common contract
and quality surfaces.

## Current Skill Set
- `api-contract.md`
- `ui-contract.md`
- `edge-cases.md`
- `permissions.md`
- `performance.md`

## Usage
- Combine these with task-specific validation commands.
- Treat them as additive checklists, not replacements for local domain
  rules.
