# Context Bundles

## Purpose
Context bundles are curated compression layers for common domains.

They are meant to give the next contributor a fast, reliable starting
point without making them manually rediscover:
- relevant AGENTS rules
- spec and agent-ref sources
- current-state caveats
- common validation focus

## Usage
1. Read `docs/architecture/current-state.md`
2. Read the relevant bundle here
3. Open the specific linked references only when needed
